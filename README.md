# Plastic-Waste-and-Recycling

Project Overview

This Tableau project focuses on analyzing plastic waste generation and recycling trends to understand how waste is produced, managed, and recycled across different regions and categories. The dashboard highlights key patterns that can help support sustainability awareness and data-driven environmental decisions.

Objectives
Analyze plastic waste generation across regions
Compare recycled vs non-recycled plastic waste
Identify trends and patterns in plastic waste management
Present insights using clear and interactive visualizations

Dashboard Highlights
Plastic waste distribution by region
Recycling vs non-recycling comparison
Trend analysis over time
Category-wise plastic waste insights
Interactive filters for better exploration

Tools Used
Tableau Desktop / Tableau Public
Data Visualization & Dashboard Design

Key Learnings
Building interactive Tableau dashboards
Creating meaningful visual stories from raw data
Using filters, charts, and layouts effectively
Understanding sustainability-focused datasets
